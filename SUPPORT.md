# Support

Use the channel that best matches the request:

- **Usage and setup questions:** check the README and relevant docs, then open an issue with a minimal, reproducible question.
- **Reproducible defects:** use the [bug report form](https://github.com/LloydCoder/Aithyrex/issues/new?template=bug_report.yml).
- **Feature proposals:** use the [feature request form](https://github.com/LloydCoder/Aithyrex/issues/new?template=feature_request.yml).
- **Security vulnerabilities:** follow [SECURITY.md](SECURITY.md); do not disclose them publicly.
- **Code of Conduct reports:** email hello@tinlance.com.

Include the commit or package version, Python version, operating system, minimal reproduction and relevant redacted logs. Never post secrets, raw customer prompts/completions, access tokens, personal data or sensitive production telemetry.

A public repository and automated CI do not imply a production support contract, response-time SLA for ordinary questions, or a guarantee that every provider/framework version is supported.
