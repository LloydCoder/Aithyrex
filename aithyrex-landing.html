Aithyrex

Agentic AI Runtime Security

Aithyrex inspects supported AI interactions for suspicious patterns and produces security findings with explicit limitations and provenance.

Engineering preview. The documented Phase 0–17 implementation sequence is complete for its declared scope. Release remains blocked pending independent AI-text evaluation, independent security review, production deployment/rollback and restore evidence, measured SLOs, and legal/compliance review. This page does not represent a production-readiness or detection-accuracy claim.

What is being built

  • Prompt-injection and credential-pattern detection.
  • Encoding and context-risk heuristics.
  • Supplementary behavioral telemetry through the separate ThreatFade service.
  • Evidence-bearing findings and integration points for downstream response workflows.

Security boundaries matter

Aithyrex produces findings; it is not an authorization grant. The Tinlance Agent Platform remains the authoritative identity, policy, approval and governed-execution layer. Auctaryn focuses on agent context and proposed-action risk. AURONTRA focuses on IT resilience and operations.

ThreatFade network-traffic results do not establish AI-text detection effectiveness. AI-specific performance claims require a separate representative evaluation corpus.

Current limitations

  • Provider wrappers are not universal transparent proxies.
  • Streaming and multimodal inputs are not supported by the current wrappers.
  • AsyncAnthropic is not supported by the current wrapper.
  • Hosted API availability, production deployment, live integrations, detection rates and compliance filing are not asserted here.
